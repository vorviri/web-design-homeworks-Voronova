# Приключения Жаба в Тёмном Лесу

Атмосферный 2D-платформер, написанный на JavaScript с использованием HTML5 Canvas API.

## Использование нейросети
- Использованная нейросеть: Qwen
- Время выполнения: 8часов
- Части игры, созданные с помощью нейросети:
  - Физика движения, гравитация, инерция и система коллизий
  - Система частиц, визуальные эффекты и анимации объектов
  - Управление состояниями игры (меню, пауза, статистика, победа/поражение)
  - Настройка бесшовного воспроизведения музыки и обработка событий UI
  - Отладка, устранение багов и оптимизация производительности


## Особенности игры
- 3 уникальных уровня с разной сложностью
- Плавная физика
- Система жизней и сбора кристаллов
- Атмосферный визуал: динамический фон, частицы, мягкое освещение
- Бесшовное воспроизведение фоновой музыки между экранами и уровнями

## Управление

 `←` `→` или `A` `D` - Движение влево/вправо
`↑` или `W` или `Пробел` - Прыжок
